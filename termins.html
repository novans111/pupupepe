Java
Объектно-ориентированный язык программирования, который разработал в компании Sun Microsystems в 1990-х годах
Oak («Дуб»)
Самое первое название языка Java. Гослинг назвал его так в честь дерева, которое росло у его окна.
JVM
Программа, которая запускает байт-код Java на любом компьютере. Это делает программы понятными для любой операционной системы. Портируемость («Напиши один раз, запускай везде»): Главный принцип Java, созданный Гослингом. Код можно написать на одном компьютере, а запустить без измененийна другом. Gosling Emacs: Ранняя версия текстового редактора Emacs на языке C, которую написал Джеймс Гослинг до создания Java
